# Foot Merge Tactic (titre de travail)

Jeu de football mobile : on collectionne des joueurs fictifs (cartes), on les
fusionne, on organise son équipe avec des zones de placement offensives et
défensives, puis un moteur simule le match en vue du dessus. Le joueur est
l'entraîneur : il ne dirige pas les footballeurs.

- **État :** conception. Pas encore de code.
- **Priorité :** le moteur de match (prototype Godot 4 en 2D envisagé, à confirmer).
