# Claude

Espace de travail partagé entre moi (jayjayc501) et Claude.

On y range tout ce qu'on construit ensemble : scripts, petits sites, outils, notes.

## Organisation

```
projets/   un dossier par projet, chacun avec son propre README
notes/     idées, recherches, brouillons
```

## Travailler avec Claude sur ce dépôt

1. Dans une nouvelle conversation, demande à Claude d'ajouter le dépôt `jayjayc501/Claude`.
2. Claude lit automatiquement `CLAUDE.md`, qui contient le contexte et les règles du dépôt.
3. Donne-lui une tâche ; il code, teste, fait le commit et peut ouvrir une pull request.
